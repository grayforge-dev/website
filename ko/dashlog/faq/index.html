시작하기

DashLog는 어떤 앱인가요?

DashLog는 달린 길을 기록하는 드라이브 기록장이에요. 주행마다 경로, 거리, 시간, 속도를 저장해서 나중에 지도와 통계로 다시 볼 수 있어요.

계정이 필요한가요?

아니요. 가입이나 로그인은 없어요. 앱을 열고 바로 기록을 시작하세요.

DashLog는 무료인가요?

네. DashLog는 현재 무료로 내려받아 쓸 수 있고, 구독도 없어요.

업무용 운행기록부나 세무 증빙으로 쓸 수 있나요?

그런 용도로 만든 앱은 아니에요. 주행을 CSV로 내보낼 수는 있지만, 세무에 바로 쓸 수 있는 양식이나 자동 분류는 제공하지 않아요.

주행은 어떻게 시작하고 끝내나요?
  • 직접: 홈 탭에서 주행 시작 버튼을 누르고, 끝낼 때는 종료 버튼을 눌러요.
  • 자동: 휴대폰이 차량 블루투스(iPhone은 CarPlay)에 연결되면 시작하고 연결이 끊기면 끝나도록 DashLog를 설정해요. 자동 기록을 참고하세요.
  • 홈 화면 위젯: 시작 버튼과 종료 버튼을 사용해요. 위젯과 알림을 참고하세요.
DashLog에는 어떤 위치 권한이 필요한가요?

앱이 요청하면 위치 접근을 허용해 주세요. 위치 접근이 차단되어 있으면 DashLog가 기록할 수 없어요. 직접 시작하는 주행은 권한이 허용되어 있기만 하면 돼요. 자동 기록은 앱이 닫혀 있는 상태에서 시작되므로 항상 허용 권한이 필요해요.

자동 기록

주행을 자동으로 기록하려면 어떻게 하나요?

Android (Android 12 이상)

  1. 설정 › 자동화 › 차량 연결 시 자동 기록 메뉴를 열어요.
  2. 차량 블루투스를 한 번만 선택하세요. 그 뒤로는 휴대폰이 차량에 연결되면 주행이 시작되고, 연결이 끊기면 끝나요.

iPhone

  1. 설정 › 자동화 › 자동 기록 설정 방법 메뉴를 열어요.
  2. 단축어 앱에서 자동화를 두 개 만들어요. 하나는 휴대폰이 연결될 때 주행을 시작하고, 다른 하나는 연결이 끊길 때 주행을 끝내요. 앱 안의 안내가 모든 단계를 보여 주고, 약 1분이면 돼요. 한 번만 설정하면 돼요.
  3. 트리거는 CarPlay나 차량 블루투스를 고르세요.
iPhone에서는 왜 단축어 자동화를 직접 만들어야 하나요?

Apple은 앱이 대신 자동화를 만들게 허용하지 않아요. 한 번 설정해 두면 그다음부터는 아무것도 누르지 않아도 주행이 기록돼요.

자동 기록에는 왜 위치 접근 ‘항상 허용’이 필요한가요?

자동 기록은 앱이 닫혀 있는 동안 백그라운드에서 시작돼요. 위치 접근이 앱을 사용하는 동안에만 허용되어 있으면 그 순간에는 DashLog가 기록할 수 없어요. 자동 기록 화면(운전 자동 기록)에서 현재 권한을 확인하고 바로 바꿀 수 있어요.

차량 연결을 끊었는데 주행이 바로 끝나지 않아요.

연결이 끊긴 뒤 약 12초 후에 주행이 끝나요. 그 시간 안에 휴대폰이 다시 연결되면 같은 주행이 이어지고, 차가 아직 움직이는 중이면 멈춘 뒤에 주행이 끝나요. 잠깐 연결이 끊겼다고 주행 하나가 둘로 나뉘지 않게 하려는 동작이에요.

다른 블루투스 기기도 주행을 시작하나요? 차가 여러 대면 어떻게 하나요?

자동 기록은 내가 고른 기기에만 반응해요. 이어폰이나 다른 블루투스 기기를 연결해도 주행은 시작되지 않아요.

  • Android: 차량은 한 대만 등록할 수 있어요. 차를 바꾸려면 자동 기록 화면을 열고 차량 변경 버튼을 눌러요.
  • iPhone: 차량마다 단축어 자동화를 만들어요.
짧은 자동 주행이 저장되지 않았어요.

자동화 › 짧은 자동 주행 제외 설정이 켜져 있을 가능성이 높아요. 기본적으로 30초보다 짧은 자동 주행은 저장되지 않아요. 0~300초 사이에서 원하는 값으로 바꿀 수 있고, 0으로 두면 모든 자동 주행이 저장돼요. 직접 시작한 주행은 아무리 짧아도 항상 저장돼요.

Android에서 주행이 중간에 끊겨요.

화면이 꺼질 때 Android가 앱을 재우고 있을 수 있어요.

  1. 설정 › 자동화 › 차량 연결 시 자동 기록 메뉴를 열어요. 백그라운드 기록 카드에서 백그라운드 실행 허용 버튼을 눌러요.
  2. 앱 정보 화면에서 배터리 옵션을 제한 없음으로 바꿔요.
  3. 샤오미, 화웨이, 오포, 비보 같은 일부 제조사는 자동 시작 또는 백그라운드 실행 설정도 따로 켜야 해요. 같은 화면에 제조사별 경로가 나와 있어요.

배터리 절약 모드는 켜 둬도 괜찮아요. DashLog는 주행을 기록하는 동안에만 GPS를 사용해요.

기록하는 동안

화면을 끄거나 다른 앱을 써도 계속 기록되나요?

네. 기록은 백그라운드에서 계속돼요. 기록 중인지는 알림(Android) 또는 잠금 화면과 다이내믹 아일랜드의 라이브 액티비티 기능(iPhone)에서 확인할 수 있어요.

기록하는 동안 화면 위쪽에 알림이 계속 떠 있어요 (Android).

Android는 앱이 백그라운드에서 위치를 기록하는 동안 알림을 표시하도록 요구해요. 이 알림은 주행을 기록하는 동안에만 보이고, 주행이 끝나면 사라져요. 알림에는 주행을 끝내는 버튼이 있어요.

주행 종료를 깜빡했어요.

15분 동안 움직임이 없으면 DashLog가 알림을 보내요. 주행을 스스로 끝내지는 않아요. 설정 › 기록 도우미 › 종료 깜빡했을 때 알림 항목에서 이 알림을 끌 수 있어요. 자동 기록은 차량 연결이 끊기면 끝나요.

주행 중에 앱이 강제 종료되거나 휴대폰이 꺼졌어요.

DashLog는 기록하는 동안 몇 초마다 현재 상태를 저장해요. 다음에 앱을 열면 마지막으로 저장된 지점까지의 주행을 복구해요.

주행을 일시정지할 수 있나요?

지금은 안 돼요. 멈춰 있던 시간도 주행 시간에 포함돼요. 이동을 나누고 싶다면 주행을 끝내고 새로 시작하세요.

시작 버튼을 눌러도 아무것도 기록되지 않아요.
  1. 위치 접근이 차단되어 있으면 앱에 “위치 권한이 차단되어 있습니다. 주행을 기록하려면 기기 설정에서 위치 권한을 허용해주세요.”라는 안내가 나와요. 설정 열기 버튼을 누르고 위치를 허용해 주세요.
  2. 위치 서비스가 꺼져 있으면 앱에 “기기의 위치 서비스가 꺼져 있습니다. 주행을 기록하려면 위치 서비스를 켜주세요.”라는 안내가 나와요. 위치 서비스를 켜 주세요.
  3. GPS는 실내나 지하에서는 느리거나 잡히지 않을 수 있어요. 탁 트인 곳에서 다시 시도해 보세요.

내 주행

거리나 속도가 차량 계기판과 달라요.

DashLog는 GPS로 계산하기 때문에 계기판이나 주행 거리계와 조금 다를 수 있어요. 정차 중 GPS가 흔들려서 거리가 늘어나는 것을 막으려고 3.6 km/h(약 2.2 mph) 미만의 움직임은 거리에 포함하지 않아요.

최고 속도나 속도 차트가 “—”로 표시돼요.

속도 데이터가 없다는 뜻이에요. 다른 앱에서 가져온 GPX 파일에 속도 값이 없으면, DashLog는 좌표로 속도를 추측하지 않고 “—”를 표시해요.

주소 대신 좌표가 보여요.

주소는 휴대폰이 온라인일 때 찾아요. 오프라인에서 끝난 주행은 좌표가 그대로 남고, 인터넷에 연결된 상태에서 그 주행의 상세 화면을 열면 DashLog가 다시 시도해요.

경로에 점선 구간이 있어요.

GPS 신호가 5초 넘게 들어오지 않으면 지도에서 양쪽을 점선으로 이어 줘요. 터널이나 지하 주차장에서, 또는 기기나 앱이 잠시 중단됐을 때 생겨요.

주행 카드의 파란 점은 무엇인가요?

버전 1.4.4 이상: 파란 점은 아직 열어 보지 않은 주행을 나타내요. 자동으로 기록됐거나 GPX에서 가져온 주행을 찾는 데 도움이 되고, 그 주행의 상세 화면을 열면 사라져요. 안 본 주행이 있으면 기록 탭의 필터 아래에 안 본 주행 · N 알약 모양 버튼이 나타나요. 누르면 그 주행만 볼 수 있어요.

주행 이름을 바꾸거나 삭제하려면 어떻게 하나요?
  • 이름 바꾸기: 주행을 열고 제목 편집 버튼을 눌러요.
  • 삭제: 기록 탭에서 주행 카드를 왼쪽으로 밀거나 상세 화면에서 삭제해요. 삭제한 주행은 완전히 사라지고 복원할 수 없어요.
마일로 바꿀 수 있나요?

네. 설정 › 단위 메뉴를 열고 자동, 킬로미터 (km), 마일 (mi) 중에서 골라요. 기본값은 자동이고, 기기의 지역 설정을 따라요.

내보내기와 가져오기

주행을 파일로 내보낼 수 있나요?

네, 두 곳에서 할 수 있어요.

  • 주행 하나: 상세 화면에서 경로 내보내기 버튼을 누르고 GPX(다른 지도·내비게이션 앱용) 또는 CSV(스프레드시트용)를 골라요.
  • 기간별: 기록 탭에서 내보내기 버튼을 누르고, 오늘, 이번 주, 이번 달, 지난달, 올해, 직접 지정한 기간 중에서 고른 뒤 CSV나 GPX로 내보내요.
다른 앱이나 기기에서 기록한 주행을 가져올 수 있나요?

네. GPS 시계, 사이클링 컴퓨터, 블랙박스, 그 밖의 추적 앱이나 지도 앱에서 내보낸 GPX 파일을 가져올 수 있어요.

  • 기록 탭에서 가져오기 버튼을 누르고 GPX 파일 선택 항목을 골라요. 파일 앱이나 다른 앱에서 GPX 파일을 DashLog로 열 수도 있어요.
  • 파일에는 시간 정보가 있는 위치가 들어 있어야 해요. 시간이 없으면 DashLog가 주행 시간과 속도를 계산할 수 없어요.
DashLog는 어떤 GPX 파일을 가져올 수 있나요?
  • 형식: GPX 1.0과 1.1.
  • 필수: 점마다 위도, 경도, 시간이 있고 점이 2개 이상인 트랙. 루트(rte)나 웨이포인트(wpt)만 들어 있는 파일은 가져올 수 없어요.
  • 속도: 파일에 점별 속도가 있을 때만 사용해요. GPX 1.0의 speed 요소, 또는 TrackPointExtension v2 확장의 speed 값(m/s)을 읽어요. 이런 값이 없으면 속도는 “—”로 표시돼요. 속도가 없는 파일도 많아요.
  • 고도: 점마다 고도(ele)가 있으면 저장해요.
  • 한 파일에 트랙이 여러 개: 하나의 주행으로 합쳐져요.
  • 거리와 시간: 좌표와 시간으로 계산해요.
  • 크기: 최대 256 MB. 점이 100,000개를 넘으면 DashLog는 솎아 낸 점들만 저장하지만, 거리, 시간, 최고 속도는 모든 점으로 계산해요.
DashLog에서 내보낸 GPX 파일은 어디서 열 수 있나요?

이 파일은 점마다 위치, 시간, 속도가 들어 있는 표준 GPX 1.1이라서 GPX를 지원하는 앱이면 열 수 있어요. 거리, 시간, 속도 요약은 같은 파일 안의 DashLog 전용 확장 영역에 저장돼요.

DashLog에서 내보낸 GPX 파일을 다시 가져오면 수치가 그대로인가요?

네. DashLog는 파일에 저장된 요약(거리, 시간, 평균 속도와 최고 속도)을 복원해요. 다른 프로그램에서 경로를 편집해서 요약과 맞지 않게 되면, DashLog는 요약을 무시하고 점으로 다시 계산해요.

GPX 가져오기에 실패했어요.

앱에 표시된 메시지를 확인해 보세요.

  • “경로 포인트에 시간 정보가 없어요. 주행 시간과 속도 계산을 위해 시간이 필요합니다.” 다른 앱에서 시간 정보를 포함해 파일을 다시 내보내세요.
  • “선택한 파일을 읽을 수 없어요. 기기에 다운로드한 뒤 다시 시도해 주세요.” 파일을 기기에 저장한 뒤 다시 시도하세요.
  • “GPX 파일이 너무 커서 가져올 수 없어요. 더 짧은 경로로 나눈 뒤 다시 시도해 주세요.” 더 짧은 트랙으로 나누세요.
  • “올바른 GPX 파일이 아닌 것 같아요.” 확장자가 .gpx인 트랙 파일이 맞는지 확인하세요.
  • “이 GPX 파일에서 경로 포인트를 찾지 못했어요.” 파일에 루트나 웨이포인트만 들어 있을 수 있어요. 트랙으로 내보내세요.
주행 기록을 새 휴대폰으로 옮기려면 어떻게 하나요?

DashLog에는 계정이나 클라우드 동기화가 없어서 주행 기록은 기기에만 있어요. 옮기려면 각 주행의 상세 화면에서 경로 내보내기 버튼으로 주행을 GPX로 하나씩 내보낸 다음, 새 휴대폰에서 파일을 하나씩 가져오세요.

이럴 때는 기간별 내보내기를 쓰지 마세요. 기간별 내보내기는 모든 주행을 각각 별도의 트랙으로 한 파일에 담기 때문에, 그 파일을 가져오면 주행이 하나로 합쳐져요. 앱을 삭제하기 전에 주행을 먼저 내보내 두세요.

위젯과 알림

홈 화면 위젯이 있나요?

네. 위젯은 두 가지이고, 각각 시작 버튼과 종료 버튼만 있어요. 주행을 기록 중인지는 표시하지 않아요.

  • DashLog: 앱을 열지 않고 백그라운드에서 주행을 시작하고 끝내요 (추천).
  • DashLog · 앱 열기: 앱을 연 다음 주행을 시작하거나 끝내요.

추가하려면 홈 화면의 빈 곳을 길게 누르세요. iPhone에서는 +를 누르고 DashLog를 검색해요. Android에서는 위젯을 누르고 DashLog를 찾아요. 최신 버전 앱에는 설정 › 기록 도우미 › 홈 화면 위젯 메뉴에 안내도 있고, Android에서는 홈 화면에 추가 버튼으로 위젯을 바로 추가할 수 있어요.

시작·종료 알림은 무엇인가요?

주행이 시작되고 끝날 때 알려 주는 알림이에요. 설정 › 기록 도우미 › 시작·종료 알림 항목에서 끌 수 있어요. 끄면 자동 주행이 시작됐는지 알기 더 어려워요.

라이브 액티비티는 무엇인가요?

iPhone에서 주행의 현재 거리와 상태를 잠금 화면과 다이내믹 아일랜드에 보여 줘요. 설정 › 기록 도우미 › 라이브 액티비티 항목에서 끌 수 있어요.

화면과 기능

지도 탭과 통계 탭에서는 무엇을 볼 수 있나요?
  • 지도: 주행에서 도착한 장소를 한 지도에 모아 보여 주고, 장소마다 몇 번 도착했는지도 보여 줘요.
  • 통계: 오늘, 이번 주, 이번 달, 올해, 전체 기간의 하이라이트와, 언제 가장 많이 운전하는지 보여 주는 주행 패턴 항목이 있어요. 색이 짙을수록 주행 시간이 길어요.
지난 주행을 다시 재생해 볼 수 있나요?

네. 주행을 열고 경로 재생 버튼을 누르면 경로를 따라 주행이 재생돼요. 재생, 일시정지 버튼을 쓸 수 있고, 속도 설정을 바꾸거나, 주행 시점 보기와 지도 보기 보기를 전환할 수도 있어요.

앱 언어를 바꿀 수 있나요?

앱은 기기 언어를 따르고, 앱 안에 언어 메뉴는 따로 없어요. DashLog만 다른 언어로 설정하려면 iPhone에서는 설정 앱을 열어 DashLog를 선택한 다음 언어를 고르세요. Android 13 이상에서는 시스템의 앱별 언어 설정을 사용하세요.

다크 모드를 쓸 수 있나요?

네. 설정 › 테마 메뉴를 열고 시스템 설정, 라이트, 다크 중에서 골라요. 기본값은 기기 설정을 따라요.

DashLog가 CarPlay나 Android Auto 화면에 나오나요?

아니요, DashLog는 차량 디스플레이용 앱이 아니에요. 다만 iPhone에서는 CarPlay 연결로 자동 기록을 시작하고 끝낼 수 있어요. 자동 기록을 참고하세요.

개인정보와 데이터

내 주행 기록이 서버로 업로드되나요?

DashLog는 주행 기록을 받는 서버를 운영하지 않아요. 경로, 거리, 속도는 내 기기에만 남아요. DashLog는 제한적인 분석과 오류 보고를 위해 Google Firebase를 사용하며, 여기에는 정확한 GPS 경로가 포함되지 않도록 설계되어 있어요. 지도는 Google Maps에서 제공해요. 자세한 내용은 개인정보 처리방침을 확인하세요.

데이터는 어디에 저장되고, 앱을 삭제하면 어떻게 되나요?

내 기기에만 저장돼요. 앱이나 앱 데이터를 삭제하면 주행 기록도 함께 삭제되고, 먼저 내보내 두지 않았다면 복원할 수 없어요.

앱을 업데이트하면 주행 기록이 지워지나요?

아니요. 앱을 업데이트해도 주행 기록은 삭제되지 않아요. 앱이나 앱 데이터를 삭제하거나 직접 주행을 삭제할 때만 지워져요.

인터넷 연결이 필요한가요?

기록은 오프라인에서도 돼요. 주소 찾기와 지도 표시에는 연결이 필요해요. 오프라인에서 끝난 주행의 주소는 나중에 연결되었을 때 채워져요.

배터리를 많이 쓰나요?

DashLog는 주행을 기록하는 동안 GPS를 계속 사용하므로 배터리가 어느 정도 소모돼요. 주행을 기록하지 않을 때는 GPS를 사용하지 않아요.
