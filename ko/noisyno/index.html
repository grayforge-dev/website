왜 NoisyNo인가요?

가장 중요한 기준은 “내 녹음이 어디로 가는가”입니다.

많은 음성 노이즈 제거 도구는 파일을 웹사이트나 서버에 올린 뒤 처리합니다. NoisyNo는 반대로 처리 모델을 앱 안에 넣었습니다. 그래서 회의, 인터뷰, 개인 메모처럼 밖으로 보내기 애매한 녹음도 휴대폰 안에서 정리할 수 있습니다.

서버 없이 오프라인 처리

앱 설치 후에는 노이즈 제거 모델이 기기 안에서 실행됩니다. 지하철, 비행기, 신호가 약한 장소에서도 처리할 수 있습니다.

계정 없이 바로 사용

회원가입, 로그인, 작업 공간 생성 같은 절차 없이 파일을 고르고 정리합니다. 녹음 파일을 정리하기 위해 계정을 만들 필요가 없습니다.

구독 없음

노이즈 제거는 무료로 사용할 수 있고 구독은 없습니다. 라우드니스 정규화가 필요하면 Pro를 1회성 인앱 구매로 열 수 있습니다.

사용하기 좋은 상황

“목소리는 괜찮은데 배경 소음이 거슬릴 때”를 위한 앱.

카페 소음, 에어컨 소리, 노트북 팬, 방 안의 웅웅거림, 바람 소리처럼 계속 깔리는 소음을 줄이는 데 초점을 둡니다. 완전히 망가진 녹음을 마법처럼 복구하는 앱이 아니라, 들을 수는 있지만 지저분한 음성 녹음을 더 깔끔하게 만드는 도구입니다.

간단한 사용 흐름

파일 선택, 정리, 비교, 공유.

녹음 파일이나 영상 파일을 선택합니다

WAV, MP3, M4A, FLAC, MP4, MOV, M4V를 지원합니다. Android에서는 OGG, Opus, 3GP, 3GPP도 지원합니다.

Clean을 누릅니다

음성 노이즈 제거가 스마트폰 안에서 실행됩니다. 업로드 대기 시간이나 서버 처리 대기열이 없습니다.

원본과 결과를 비교한 뒤 저장합니다

같은 위치에서 Original/Cleaned를 바꿔 들어보고, 결과를 M4A(AAC) 또는 WAV(16-bit)로 저장하거나 공유할 수 있습니다.

이런 상황에 좋습니다

오프라인, 계정 없음, 구독 없음이 중요한 사람에게.

민감한 회의 녹음, 밖으로 보내기 애매한 개인 메모, 인터넷이 안 되는 환경에서의 작업처럼 파일을 웹에 올리기 어려운 상황을 위해 만들었습니다.

회의 녹음

회의 내용이 민감할 때 웹 업로드 대신 휴대폰에서 처리합니다.

인터뷰와 강의

카페, 강의실, 야외에서 녹음된 목소리를 더 듣기 쉽게 정리합니다.

영상 오디오

지원되는 영상 파일에서 오디오를 뽑아 노이즈 제거 후 오디오 파일로 저장합니다.

FAQ

자주 묻는 질문

NoisyNo는 음성 파일을 서버에 업로드하나요?

아니요. 노이즈 제거 처리는 스마트폰 안에서 실행됩니다. 선택한 파일과 결과 파일은 GrayForge 서버에 업로드되지 않습니다.

인터넷 없이 오프라인에서도 쓸 수 있나요?

예. 앱 설치 후에는 노이즈 제거 모델이 기기 안에서 실행되므로 인터넷 연결 없이도 녹음 소음 제거가 가능합니다.

계정 없이 사용할 수 있나요?

예. NoisyNo는 회원가입이나 로그인 없이 사용할 수 있습니다.

구독이 필요한가요?

아니요. 노이즈 제거 기능은 무료로 사용할 수 있고 구독은 없습니다. 라우드니스 정규화는 Pro 기능이며 1회성 인앱 구매로 제공됩니다.

어떤 파일 형식을 지원하나요?

WAV, MP3, M4A, FLAC, MP4, MOV, M4V 입력을 지원합니다. Android에서는 OGG, Opus, 3GP, 3GPP도 지원합니다. 출력은 M4A(AAC)와 WAV(16-bit)를 지원합니다.

개인정보나 진단 데이터는 전혀 없나요?

오디오 파일은 업로드하지 않습니다. 다만 앱 안정성과 사용 흐름 파악을 위한 제한적인 익명 분석 및 크래시 진단은 개인정보 처리방침에 설명된 범위에서 사용됩니다.
